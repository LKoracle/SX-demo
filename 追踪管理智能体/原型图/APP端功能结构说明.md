## 三、AskBob 聊天界面

点击"问Bob>"或任意快捷入口后，从底部上滑展开全屏聊天覆盖层。

### 3.1 界面组成

- 顶部导航栏（AskBob 标题 + 返回 + 菜单）
- 对话消息区（气泡式，AI左/用户右）
- AI思考泡（可折叠展开，显示思考步骤）
- 底部输入框（文本输入 + 发送）

### 3.2 Query 路由规则（interpretQuery）

优先级从高到低：

| 触发关键词 | 路由结果 |
|-----------|---------|
| 代理人姓名（精确匹配） | 该代理人的面谈记录 |
| `MBO面谈` / `MBO` + `未完成/待开展` | MBO面谈未完成名单 |
| `P序列晋升临界` / `P序列` + `晋升` / `P4` | P序列晋升临界名单 |
| `下个月能达成钻石` / `下个月` + `达成钻石` | 达钻潜力代理人名单（主题型） |
| `距离钻石还差` / `钻石` + `还差` | 差300元达钻名单 |
| `钻石达成` | 钻石达成代理人名单 |
| `达钻潜力` | 达钻潜力代理人名单（主题型） |
| `连钻` | 连钻名单 |
| `达钻临界` / `未达钻` / `达钻` | 达钻临界名单（差额500元内） |
| `司庆` | 司庆季绩优名单 |
| `档案` | 代理人档案（全量） |
| `面谈` / `开展` | 进入两步选择流程 |
| `哪些人` | 通用待面谈名单 |
| `保单` | 承保代理人名单 |

## 四、面谈管理流程

### 4.1 两步引导式选择流程

**Step 1：选择面谈月份**
- 选项：本月、下月、下下月（动态生成）
- 用户选择后以气泡确认

**Step 2：选择面谈主题**

| 主题类型 | 主题 | 说明 |
|---------|------|------|
| 固定主题 | 6-8月服务季面谈 | 52人待面谈 |
| 固定主题 | 医疗险绩优面谈 | 18人待面谈 |
| 固定主题 | MBO面谈 | 9人待面谈 |
| AI推荐 | 达钻潜力人员 | FYC差额300元内人员 |

用户选择后触发 AI 思考 → 返回代理人名单卡片。

## 五、代理人名单卡片类型

所有卡片均为"AI消息气泡 + 列表卡片"组合，默认展示 Top 3，可点击"查看全部"进入底部浮层。

### 5.1 通用待面谈名单

- 按优先级排序（待面谈场次 × P值加权）
- 每行显示：姓名 + P/M值 + 营业部 + 面谈主题 + 推荐理由
- 支持下载按钮

### 5.2 MBO面谈名单

- 展示 MBO 面谈未完成代理人
- 每行：姓名 / P值 / M值 / 营业部 / 面谈主题

### 5.3 P序列晋升临界名单

- 筛选 FYC 距 P 序列晋升差额 ≤1000 元
- 每行额外展示：距P序列晋升差额（元）

### 5.4 达钻潜力名单（预测型）

- 下个月有望达钻的代理人
- 每行额外展示：当前钻石等级徽标（含背景色） + 距目标等级差额（红色）

### 5.5 差300元达钻名单

- FYC 距钻石差额 ≤300 元
- 每行额外展示：当前钻石等级徽标 + 距目标等级差额（红色）

### 5.6 连钻名单

- 连续达钻 12 个月及以上
- 每行额外展示：当前钻石等级徽标 + 连钻月数（蓝色）

### 5.7 承保代理人名单

触发方式：query `保单` 

每行布局：
```
姓名  P值/M值
营业部
承保XX张保单      ← 第3行：纯文字彩色，无背景



### 5.8 达钻潜力代理人名单（主题型）

触发方式：query `达钻潜力` 或面谈主题选"达钻潜力人员"，两路展示同一列表。

每行布局：
```
姓名  P值/M值
营业部
[钻石等级]          ← 第3行：纯文字彩色，无背景
距钻石差额 XXX元  距钻石件数差距 X件  ← 第4行
```

### 5.9 钻石达成代理人名单（主题型）

触发方式：query `钻石达成`。

每行布局：
```
姓名  P值/M值
营业部
[钻石等级] 连钻 XX月  ← 第3行，纯文字彩色，无背景
```

### 5.10 代理人档案（全量）

- 显示所有代理人（含已完成面谈）
- 待面谈者显示面谈主题，已完成不显示主题

## 六、全量名单底部浮层（Bottom Sheet）

点击"查看全部 N 人"后从底部滑出。

### 功能组成

| 功能 | 说明 |
|------|------|
| 搜索框 | 按姓名/网点/营业部实时过滤 |
| 筛选营业单位 | 进入五级组织筛选面板 |
| 下载按钮 | 推送至邮箱（可设置定时任务） |
| 分页列表 | 每次加载10条，底部"加载更多" |

### 五级组织筛选面板

```
全部
└── 二级机构（省）：浙江 / 广东 / 江苏 / 山东 / 上海 / 北京 / 四川
    └── 三级机构（市）
        └── 业务发展区（区）
            └── 网点
                └── 营业部
```

- 面包屑导航支持任意层级跳回
- 确定后过滤列表

## 七、代理人档案详情弹窗

在底部浮层或聊天卡片中点击"详情"后，从底部滑出个人档案全屏卡片。

### 月份切换

支持切换查看 1月～5月（2026年）数据。

### 数据维度

**业绩收入**
| 卡片 | 指标 |
|------|------|
| FYC达成进展 | 进度条（达成率%）+ 已达成金额 / 目标金额，含"预警考核"/"收入明细"次级入口 |
| 业绩追踪 | 预收FYP（元）/ 预收件数 |
| 钻石达成 | 访前件数 / 访前FYC（元）/ 当月钻石等级 |

**客户经营**
| 卡片 | 指标 |
|------|------|
| 客经工作台 | 客户经营完成率 / 经营量 |
| 客户资源 | 存量客户（人）/ 目标客户（人） |

**队伍发展**
| 卡片 | 指标 |
|------|------|
| 增员追踪 | 潜能评估（人）/ 职岗培训（人） |
| 团队看板 | P职级人数 / M职级人数 |

## 八、下载与定时任务

- 任意名单卡片右上角均有"下载"按钮
- 点击下载 → AI 回复：正在为您推送至邮箱
- AI 随后引导设置**定时任务**（频率：每月N日X时 / 每周X X时 / 每天X时）
- 定时任务设置后，系统将按频率自动筛选并推送最新代理人名单

## 九、钻石等级体系

系统内使用的钻石等级及对应色彩：

| 等级 | 颜色 |
|------|------|
| 未达钻 | 灰色 `#94a3b8` |
| 钻石 | 蓝色 `#1976e8` |
| 银钻 | 深灰 `#64748b` |
| 金钻 | 橙黄 `#d97706` |
| 双金钻 | 深橙 `#b45309` |
| 铂金MVP | 紫色 `#7c3aed` |
| 黑金MVP | 深色 `#1e293b` |
| 双黑金MVP | 深色 `#1e293b` |

**徽标显示规则**：
- 名单卡片内（达钻潜力/钻石达成主题）：纯文字彩色，无背景色
- 其他场景（档案弹窗/通用卡片）：带背景色 + 圆角填充
