# 平安 DO APP · 追踪管理智能体功能结构说明

版本：v20260725  
依据原型：`原型图/APP端20260725版本.html`  
适用范围：APP 端首页、AskBob 对话层、代理人名单、面谈助手及其二级页面。

## 1. 总体结构

APP 端以首页为主入口，通过 AskBob 智能问答和功能卡片承接追踪、面谈、客户经营、钻石达成等场景。

```text
APP 首页
├─ 顶部问候与快捷入口
├─ 经营指标横滑卡片
│  ├─ 达成业绩
│  ├─ 人力指标
│  └─ FYC 达成
├─ AskBob 智能助手
│  ├─ 输入 query
│  ├─ 推荐问题
│  ├─ 意图识别
│  ├─ 代理人结果卡
│  └─ 全量名单 Bottom Sheet
├─ 重点功能卡片
│  ├─ 面谈指引
│  └─ 队伍贺报
├─ 功能宫格
├─ 产品宝典
├─ 推动素材
└─ 底部导航
```

## 2. 首页功能结构

### 2.1 顶部信息区

顶部展示当前用户问候、用户层级与机构信息：

- 主文案：`费**，下午好`
- 副文案：`三级机构用户-浙江温州市`
- 右侧包含搜索图标与扫码图标。

### 2.2 经营指标横滑卡片

首页顶部指标区为横向滚动卡片，共三张。

| 卡片 | 核心字段 | 说明 |
| --- | --- | --- |
| 达成业绩 | NBEV、FYP、预收保费、预收保费(下月生效) | 每项展示当日、月累计、年累计 |
| 人力指标 | 当前人力、新增人力、脱落人力、钻石人力占比、钻石会员占比、一年内新人活动率 | 用于经营者快速查看队伍盘面 |
| FYC 达成 | 达成率、已达成、目标、缺口 | 用环形进度呈现月度达成 |

### 2.3 AskBob 智能助手入口

首页 AskBob 卡片支持以下入口：

- 点击 AskBob 主卡片：打开对话层，等待用户输入。
- 点击 `面谈辅导`：以 `我要开展面谈` 进入对话。
- 点击 `自动化追踪`：Toast 提示 `敬请期待`。

### 2.4 重点功能卡片

| 卡片 | 行为 |
| --- | --- |
| 面谈指引 | 以 `还要面谈哪些人？` 进入 AskBob 对话 |
| 队伍贺报 | Toast 提示 `敬请期待` |

### 2.5 功能宫格

功能宫格包含：

- 业绩追踪
- 常规战报
- 团队发展看板
- 钻石贺报
- 钻石预警
- 增员追踪
- 架构图
- 意健险追踪
- 智慧班务
- 更多

当前原型中宫格主要用于展示入口，不是本轮 AskBob query 的主要承接路径。

### 2.6 推动素材

首页素材区展示三类海报入口：

- e 生保客群海报
- 御享分红 26 客群海报
- 御享金越年金客群海报

### 2.7 底部导航

底部导航包含：

- 首页
- 待办
- 客户
- 消息，带红点提示
- 我的

## 3. AskBob 对话层

### 3.1 对话层结构

AskBob 打开后覆盖当前 APP 页面，包含：

- 顶部栏：返回按钮、标题 `AskBob`、菜单按钮。
- 欢迎语：`嗨！有什么可以帮您`
- 猜你想问：
  - 推荐下个月能达成钻石的代理人
  - 我要开展 6 月的面谈
  - 查询要开展医疗险绩优面谈的代理人
- 底部输入框：支持用户输入 query。

### 3.2 对话流程

用户输入 query 后，系统执行：

1. 识别 query 意图。
2. 展示思考过程。
3. 输出说明文案。
4. 输出对应结果卡片。
5. 输出推荐追问 chip。

推荐追问 chip 当前包括：

- 帮我查询距离钻石还差 300C 的代理人
- 帮我推荐次月达银钻潜力代理人
- 本月访后达成银钻代理人明细

## 4. Query 意图路由

| 用户 query 命中 | 意图类型 | 输出页面或卡片 |
| --- | --- | --- |
| 精确代理人姓名 | `name` | 指定代理人的面谈记录 |
| MBO 面谈、MBO 未完成、MBO 待开展 | `mboList` | 2026 年 5 月面谈名单 |
| P 序列晋升临界、P 序列晋升、P4 | `pSeriesGap` | P 序列晋升临界名单 |
| 下个月能达成钻石 | `nextMonthDiamond` | 达钻潜力代理人 |
| 距离钻石还差、钻石还差 | `diamond300c` | 差 300 元达钻名单 |
| 钻石达成 | `all` + 钻石达成主题 | 钻石达成代理人 |
| 达钻潜力 | `all` + 达钻潜力主题 | 达钻潜力代理人 |
| 连钻 | `diamondStreak` | 连钻名单 |
| 达钻临界、未达钻、达钻 | `diamondGap` | 达钻临界名单 |
| 客户经营、客经 | `customerOperation` | 客户经营代理人 |

| 面谈、开展 | `conduct` | 面谈月份选择 + 面谈主题选择 |
| 哪些人 | `all` | AI 重点面谈推荐 |
| 保单 | `policy` | 承保代理人名单 |

## 5. 面谈 query 流程

当用户输入面谈类 query，例如 `我要开展面谈`、`我要开展6月的面谈` 时，进入两步选择流程。

### 5.1 第一步：选择面谈月份

系统展示月份选择卡，支持：

- 本月
- 下月
- 下下月

用户选择后，系统追加用户气泡：`面谈月份：YYYY年MM月`。

### 5.2 第二步：选择面谈主题

系统展示面谈主题卡，包含固定主题与 AI 推荐主题。

固定主题：

- 6-8 月服务季面谈，52 人待面谈
- 医疗险绩优面谈，18 人待面谈
- MBO 面谈，9 人待面谈

AI 推荐：

- 达钻潜力人员
- 说明：FYC 差额 300 元内人员

选择主题后，系统输出对应面谈名单或达钻名单。

## 6. 代理人结果卡片

### 6.1 通用能力

代理人结果卡一般包含：

- 卡片标题
- 预览名单
- 代理人姓名
- P/M 职级
- 组织信息
- 主题或指标信息
- 详情按钮
- 查看全部入口
- 导出按钮

卡片右上角导出按钮会触发下载任务。

### 6.2 待面谈名单

用于面谈主题、`哪些人`、司庆等 query。

展示逻辑：

- 按代理人聚合多条面谈主题。
- 根据主题数量与职级排序。
- 每个代理人展示推荐理由。
- 点击 `详情` 进入面谈助手。
- 点击 `查看全部` 打开全量名单 Bottom Sheet。

### 6.3 代理人档案

由 `档案` query 触发。

展示逻辑：

- 按代理人聚合面谈记录。
- 预览 5 条记录。
- 待开展或紧急状态展示 `详情` 按钮。
- 已完成状态展示完成标识。

### 6.4 达钻相关卡片

| 卡片 | 触发 query | 展示字段 |
| --- | --- | --- |
| 达钻潜力代理人 | 下个月能达成钻石、达钻潜力 | 姓名、P/M、组织、当前钻石等级、距下一级 FYC 差距、件数差距 |
| 差 300 元达钻名单 | 距离钻石还差、钻石还差 | 姓名、P/M、组织、当前等级、目标等级、差额 |
| 达钻临界名单 | 达钻临界、未达钻、达钻 | 姓名、P/M、组织、距钻石差额 |
| 连钻名单 | 连钻 | 姓名、P/M、组织、当前等级、FYC 达成、长连钻月数 |
| 钻石达成代理人 | 钻石达成 | 姓名、P/M、组织、钻石等级、FYC、长连钻月数 |

钻石等级使用不同色彩示意，包含：

- 未达钻
- 钻石
- 银钻
- 金钻
- 双金钻
- 铂金 MVP
- 黑金 MVP
- 双黑金 MVP

### 6.5 保单 query 卡片

由 `保单` query 触发，输出 `承保代理人名单`。

卡片字段：

- 姓名
- P/M 职级
- 网点/营业部
- 承保 FYP
- 承保件数
- 详情按钮，当前为 Toast 提示

### 6.6 客户经营 query 卡片

由 `客户经营` 或 `客经` query 触发，输出 `客户经营代理人`。

卡片字段：

- 第 1 行：姓名、P/M 职级
- 第 2 行：营业部
- 第 3 行：盘客量、经营量
- 第 4 行：经营完成率、升温量
- 详情按钮，当前 Toast 提示 `已为代理人生成客户经营建议`

## 7. 全量名单 Bottom Sheet

点击结果卡的 `查看全部` 后打开全量名单 Bottom Sheet。

### 7.1 基础结构

Bottom Sheet 包含：

- 标题与数量
- 搜索框
- `筛选营业单位` 按钮
- 导出按钮
- 代理人列表
- 分页加载区域

### 7.2 搜索能力

搜索框支持按以下字段检索：

- 姓名
- 网点
- 营业部

### 7.3 分页能力

列表每页加载 10 条。

- 初始展示 10 条。
- 点击加载更多继续追加。
- 全部加载完成后展示 `已显示全部`。

### 7.4 营业组织筛选

组织筛选支持五级结构：

1. 二级机构
2. 三级机构
3. 业务发展区
4. 网点
5. 营业部

筛选面板提供面包屑导航，可回退到任意层级重新选择。点击确认后，Bottom Sheet 列表按所选组织过滤。

### 7.5 导出能力

Bottom Sheet 右上角导出按钮会基于当前列表触发下载任务。

## 8. 面谈助手

面谈助手由代理人名单中的 `详情` 按钮进入，是一个全屏二级页面。

```text
面谈助手
├─ 顶部栏
├─ 代理人摘要
├─ 面谈准备
│  ├─ AI洞察 / 面谈要点
│  └─ 面谈指引
├─ 代理人档案
│  ├─ 月份选择
│  ├─ 经营画像
│  ├─ 客户经营
│  ├─ 队伍发展
│  └─ 面谈历史
└─ 底部工具栏
```

### 8.1 代理人摘要

代理人摘要卡点击后进入 `个人信息` 页面。

当前摘要展示：

- 代理人姓名
- 标签：高才、双金钻、连钻 15 月
- 工号
- P/M 职级
- 所属组织
- FYC 缺口
- 高温客户
- 建议约访

### 8.2 面谈准备

面谈准备区包含：

- AI 洞察 / 面谈要点：展示两条带标题的洞察文案。
- 面谈指引：点击进入 `面谈指引` 二级页面。

AI 洞察当前为信息展示，不单独跳转。

### 8.3 代理人档案

代理人档案支持月份选择，默认 `2026年05月`。切换月份后刷新下方指标。

#### 经营画像

| 卡片 | 行为 | 展示内容 |
| --- | --- | --- |
| FYC 达成进展 | 进入 `FYC 达成进展` | 达成率、已达成、目标、缺口 |
| 业绩追踪 | 进入 `业绩追踪` | 预收 FYP、预收件数 |
| 钻石达成 | 进入 `钻石达成` | 当前等级、访前件数、访前 FYC |

FYC 达成进展卡内还有两个快捷入口：

- 预警考核：Toast `敬请期待`
- 收入明细：进入 `个人收入`

#### 客户经营

| 卡片 | 行为 | 展示内容 |
| --- | --- | --- |
| 客经工作台 | 进入 `客经工作台` | 完成率、经营量 |
| 客户资源 | 进入 `客户资源` | 存量客户、目标客户 |

#### 队伍发展

| 卡片 | 当前行为 |
| --- | --- |
| 增员追踪 | Toast `以PRD UI为准` |
| 团队看板 | Toast `以PRD UI为准` |

#### 面谈历史

| 卡片 | 行为 |
| --- | --- |
| 面谈档案 | 进入 `面谈档案` |

面谈档案摘要展示：

- 年面谈次数
- 最近面谈日期

### 8.4 底部工具栏

底部固定工具栏包含：

| 工具 | 行为 |
| --- | --- |
| 面谈总结 | 进入 `面谈总结` |
| 收入计算器 | 进入 `收入计算器` |
| 架构图 | 进入 `架构图` |
| 保存图片 | Toast `敬请期待` |

## 9. 面谈助手二级页面

### 9.1 面谈指引

页面包含：

- 绩效面谈 / 增员面谈 Tab
- 面谈框架
- 话术指引

面谈框架分三层：

- 谈目标：拉近关系、找动力、确定目标
- 盘客户：查名单、筛重点
- 定行动：定访量、强信心

话术指引支持折叠展开，并在部分模块提供 `换一换` Toast。

### 9.2 FYC 达成进展

展示代理人 FYC 月度趋势：

- 年份切换：2024、2025、2026
- 月度折线图
- 目标线
- 月度明细

### 9.3 业绩追踪

页面支持：

- 年度 / 季度 / 月度切换
- 时间选择
- 预收、承保相关指标
- 建议书清单
- 预收清单
- 承保清单

### 9.4 客经工作台

页面支持按时间周期查看客户经营情况：

- 年度
- 季度
- 月度

核心能力：

- 筛选经营动作
- 查看触客、面访、邀约等动作数据
- 查看完成量、升温量、转化量
- 查看目标、完成、差距

### 9.5 客户资源

客户资源页包括：

- 客户地图
- 触访转追踪
- 筛选
- 时间维度切换
- 月份选择
- 数据维度切换
- 横向滚动表格
- 客户名单面板

客户资源支持的维度：

- 客户价值
- 客户温度：高温、中温、低温、冷却
- 客户类型
- 客群标签

客户列表展示：

- 客户 ID
- 姓名
- 客户价值标签
- 客温标签
- 客群标签
- 面访记录

### 9.6 钻石达成

页面展示：

- 近 6 个月钻石等级时间线
- 当前钻石等级
- 各钻石等级目标与当前达成
- FYC 差距
- 件数差距

等级图标使用钻石形态，并按等级配置不同颜色。

### 9.7 增员追踪

二级页面包含：

- 月份选择
- 增员漏斗
- 阶段 Tab
- 阶段名单

阶段包括：

- 创说会
- AI 云面试
- 岗前报名
- 上岗

每个名单项展示：

- 姓名
- 手机号码
- 出生日期
- 阶段时间字段

说明：面谈助手首页的 `增员追踪` 卡片当前仍保持 Toast，占位文案为 `以PRD UI为准`；二级页面代码已存在。

### 9.8 团队看板

二级页面包含：

- 季度选择
- P 职级分布
- M 职级分布

说明：面谈助手首页的 `团队看板` 卡片当前仍保持 Toast，占位文案为 `以PRD UI为准`；二级页面代码已存在。

### 9.9 面谈档案

页面展示历史面谈记录列表。

每条记录包含：

## 11. 数据与模拟规则

当前原型使用前端模拟数据驱动：

- 代理人数据规模约 1000 条。
- 面谈主题包含季度目标检视、司庆季绩优名单、月度业绩面谈、新人帮扶辅导、客户经营指导。
- 组织层级包含业务发展区、网点、营业部。
- 面谈助手内的月度数据支持 2026 年 1 月至 5 月切换。
- 客户资源使用模拟客户价值、客温、客群标签与触访转数据。
