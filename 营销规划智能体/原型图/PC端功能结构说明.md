## 三、详细功能流程

### 3.1 达成路径规划（三步卡）

**触发方式**：query 含"帮我规划达成路径"等

**Step 1：选择月度**
- 选项：2026年6月 / 7月 / 8月
- 单选，选中后自动进入下一步

**Step 2：确认 NBEV 目标（万元）**
- 预设选项 + 自定义输入框
- 选中/填写后自动进入下一步

**Step 3：选择规划路径维度**
- 多选 checkbox：队伍 / 客户 / 产品
- 点击"确认"按钮提交

**确认后流程**：
1. 生成用户合成气泡（汇总所选内容）
2. 800ms 后显示 AI 思考卡
3. 按所选维度依次展示达成卡片

**生成的卡片类型**（按维度）：

| 维度 | 卡片 |
|------|------|
| 全局 | 业务季路径规划卡 |
| 队伍 | 队伍达成测算卡 |
| 客户 | 客户达成测算卡 |
| 产品 | 产品达成测算卡 |

---

### 3.2 单路径规划

**触发方式**：query 精确为"帮我规划队伍/客户/产品达成路径"

**流程**：跳过月度选择 → 直接显示 NBEV 追问卡 → 确认后进思考卡 → 对应单张路径卡

---

### 3.3 队伍画像分析

**触发**：query 含"队伍是如何分布"/"队伍是怎么分布"

**卡片内容**：
- 机构信息：头像 + 在职人力数
- 人力分布表：双金钻 / 金钻 / 银钻 / 钻石 / 活动非钻 / 非活动人力
- 人均 NBEV 柱状图（SVG）
- 雷达图（综合对标分析）

---

### 3.4 客户画像分析

**触发**：query 含"客户是如何分布"/"客户是怎么分布"

**卡片内容**：

1. **新老客对比表**（月份可切换）
   - 列：维度 / 新客投保人数 / 新客客均NBEV / 老客投保人数 / 老客客均NBEV

2. **客温 × 客价 二维矩阵**（只读）

   |   | 冷却 | 低温 | 中高温 | 合计 |
   |---|------|------|--------|------|
   | A | 42 | 156 | 218 | 416 |
   | BC | 28 | 84 | 164 | 276 |
   | DEF | 14 | 42 | 72 | 128 |
   | 合计 | 84 | 282 | 454 | 820 |

3. **同类机构均值对标提示框**（bg #eff6ff，border #bfdbfe）

---

### 3.5 目标拆解

**触发**：query 含"目标制定"/"目标拆解"/"拆解推动目标"

**两步追问卡**：
- Step 1：选择业务季（司庆季 / 6-8月服务季）
- Step 2：确认推动目标值（默认3000万 / 自定义输入）

**拆解方案卡**（三月份 Tab 切换）：

| 功能 | 说明 |
|------|------|
| 月份切换 | 6月 / 7月 / 8月，独立数据 |
| 网点拆解表 | 网点名 + 目标输入框 + 占比 + 人力 + 参考值 |
| 平衡检查 | 合计 vs 目标，差额实时提示 |
| 确认按钮 | 月度确认后锁定输入框 |
| 版本管理 | 草稿/已确认，最多保留30天 |

**版本操作**：
- 保存草稿：修改输入后自动标记 dirty → 存入版本快照
- 确认版本：弹确认对话框 → 锁定 → 持久化
- 删除版本：仅草稿版本可删，已确认版本不可删

## 四、数据卡片详解

### 4.1 业务季路径规划卡

| 字段 | 说明 |
|------|------|
| 季度名称 | 如"2026年Q2" |
| 推动目标 | 万元 |
| 达成率 | 百分比 |
| 月度拆解 | 6月/7月/8月各自目标 + 达成率小卡 |
| 趋势图 | SVG 面积图，Y轴 0-3000万 |

---

### 4.2 队伍达成测算卡

**表格列**：等级 / 人力 / 对比期人力 / 人力占比 / 对比期占比 / 人均NBEV / 对比期人均NBEV / NBEV（万）/ NBEV占比

**数据行**：双金钻 / 金钻 / 银钻 / 钻石 / 活动非钻 + 非活动人力（灰色只读）+ 合计行 + 钻石及以上占比行

**可调整**：点击"调整队伍分布"展开追问卡，修改人力/人均NBEV后重新测算

**校验**：钻石及以上占比不能低于 12%

---

### 4.3 客户达成测算卡

**可编辑二维矩阵**：行（客价 A/BC/DEF）× 列（客温 冷却/低温/中高温），行列合计自动计算

**可调整**：点击"调整客户分布"展开矩阵输入卡，修改后重新测算 NBEV

**校验**：某客价维度 NBEV 下降 > 20% 时显示警告

---

### 4.4 产品达成测算卡

**费用测算表列**：产品 / 缴期 / 激活率 / 人均保单 / FYP / Margin / NBEV / 占比 / 操作

**操作**：
- 添加产品（选择主产品 → 子产品 → 追加行）
- 编辑（激活率/人均保单/FYP/Margin 均可编辑，NBEV 自动计算）
- 参照历史产品（Toggle 开关，选参照产品 + 参照期间自动填充数据）
- 删除产品（确认对话框）
- 多月份切换（各月数据独立）

**YoY 徽章**：`↑N.N%`（红）/ `↓N.N%`（绿）/ `持平`（灰），显示在输入框旁

---

### 4.5 达钻潜力人员名单 / 钻石达成名单

两个列表卡片结构相同：

| 功能 | 说明 |
|------|------|
| 搜索框 | 按姓名/网点/营业部实时过滤 |
| 筛选面板 | 下拉菜单，多维度筛选 |
| 分页 | 10 / 20 条/页切换 |
| 下载/导出 | 触发文件下载或 Toast 提示 |

## 五、追问卡片规范

所有追问卡片（multi-step cards）统一样式：

- 背景：white，边框 1px #e2e8f0，圆角 10px
- 标题行：含步骤标签 "1 / 3"
- Step 过渡：当前步 opacity → 0（180ms）→ display none；下一步 display block → opacity 1（180ms）
- 单选选中 → 自动进入下一步；多选 → 点击"确认"按钮提交

**选项样式**（.path-option）：
- 圆点 + 文字，hover 时背景 #eff6ff
- 选中态：边框 Primary，文字 Primary，圆点填充

**自定义输入组合**：
- 圆点 + "自定义目标" 标签 + 输入框 + 单位
- onfocus 时取消其他选项的选中态
- 有值时添加 has-value class
