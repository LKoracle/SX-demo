# 平安 DO · PC 端智能工作台功能结构说明

版本：v20260725  
依据原型：`原型图/PC端20260725版本.html`  
适用范围：PC 端 AskBob 智能工作台、对话路由、目标拆解、达成路径规划、名单工作台、代理人详情页。

## 1. 总体结构

PC 端采用“左侧会话栏 + 中央 AskBob 对话 + 右侧工作台”的三栏结构。用户先在 AskBob 中输入 query，系统输出思考过程、说明文案和工件卡；点击工件卡后，右侧工作台展开，承接复杂表格、拆解、筛选、编辑和代理人详情。

```text
PC 端智能工作台
├─ 顶部导航栏
├─ 左侧会话栏
│  ├─ AskBob 品牌区
│  ├─ 新建对话
│  ├─ 导航菜单
│  ├─ 历史会话
│  └─ 退出
├─ 中央对话区
│  ├─ 欢迎语
│  ├─ 推荐问题
│  ├─ 消息流
│  ├─ 追问卡
│  ├─ 工件卡
│  └─ 输入栏
└─ 右侧工作台
   ├─ 目标拆解工作台
   ├─ 达成路径规划工作台
   ├─ 达钻潜力人员名单
   ├─ 钻石达成代理人名单
   ├─ 承保代理人名单
   ├─ 面谈对象名单
   ├─ 代理人详情页
   └─ 代理人档案详情页
```

## 2. 全局布局

### 2.1 顶部导航栏

顶部导航栏为深色背景，包含：

- 左侧 DO 品牌标识。
- 中部产品导航菜单，当前页有激活态。
- 右侧工具图标、用户头像和用户名。

顶部导航栏底部有轻量渐变分隔线，用于区分全局导航与工作区。

### 2.2 左侧会话栏

左侧会话栏支持展开与折叠。

展开态包含：

- 返回按钮
- `AskBob` 标题
- 折叠按钮
- 新建对话
- 导航菜单
- 历史会话列表
- 退出按钮

折叠态保留图标轨，隐藏文字和历史会话内容。右侧工作台打开时，左侧会话栏会自动收起，给工作台留出空间。

### 2.3 中央对话区

中央对话区由三部分组成：

- 顶部栏：包含退出对话按钮。
- 消息区：展示 AI 气泡、用户气泡、追问卡、思考卡、工件卡。
- 输入栏：支持文字输入、回车发送、语音按钮、附件按钮、发送按钮。

默认欢迎语：

- `您好，我是AskBob。为您提供营销规划、追踪管理与内容创作`

### 2.4 右侧工作台

右侧工作台默认隐藏。点击工件卡后：

1. 左侧栏收起为图标轨。
2. 中央对话区保持窄宽。
3. 右侧工作台从右侧展开。
4. 工作台顶部展示标题、版本历史、全屏按钮等。

工作台支持：

- 打开
- 关闭
- 全屏
- Esc 退出全屏
- 版本历史
- 代理人切换
- 底部确认栏

## 3. Query 路由

PC 端 query 由 `routeQuery(query)` 统一分发。

| 用户 query 命中 | 路由结果 |
| --- | --- |
| 帮我规划达成路径、规划 + 达成路径、怎么达成 NBEV、完成 NBEV 目标、如何才能完成 | 达成路径规划三步追问 |
| 帮我规划队伍达成路径 | 单路径规划，路径为队伍 |
| 帮我规划客户达成路径 | 单路径规划，路径为客户 |
| 帮我规划产品达成路径 | 单路径规划，路径为产品 |
| 我要调整目标 | NBEV 目标值追问 |
| 队伍是如何分布、队伍是怎么分布 | 队伍画像分析 |
| 客户是如何分布、客户是怎么分布 | 客户画像分析 |
| 目标制定、目标拆解、拆解推动目标 | 目标拆解流程 |
| 达钻潜力人员、达钻潜力 | 达钻潜力人员名单工作台 |
| 钻石达成 | 钻石达成代理人名单工作台 |
| 开展面谈 | 面谈月份 + 面谈主题追问 |
| 面谈对象 | 面谈对象名单工作台 |
| 保单 | 承保代理人名单工作台 |

## 4. 对话与工件卡机制

### 4.1 标准对话流程

用户输入 query 后，一般执行：

1. 追加用户气泡。
2. 隐藏未完成的追问卡。
3. 进入路由判断。
4. 展示 AI 思考或处理中气泡。
5. 输出 AI 说明文案。
6. 输出可点击工件卡。
7. 点击工件卡打开右侧工作台。

### 4.2 工件卡

工件卡用于承接复杂结果，常见字段包括：

- 图标
- 工件标题
- AI 推荐或测算说明
- 数据数量或预测值
- `打开` 按钮

工件卡点击后不会替换对话，而是在右侧打开对应工作台。

### 4.3 推荐追问

部分结果卡完成后会追加推荐追问 chip，用于继续查询达钻、保单、面谈等相关任务。

## 5. 达成路径规划

### 5.1 触发方式

触发 query：

- `帮我规划达成路径`
- 包含 `规划` 与 `达成路径`
- 包含 `怎么达成` 与 `NBEV`
- 包含 `完成NBEV目标`
- 包含 `如何才能完成`

### 5.2 三步追问

达成路径规划使用三步合一追问卡。

1. 选择业务季
   - 司庆季
   - 6-8 月服务季

2. 确认 NBEV 目标
   - 预设目标
   - 自定义目标

3. 选择规划路径维度
   - 产品
   - 客户
   - 队伍

确认后，系统生成用户汇总气泡，并进入 AI 测算。

### 5.3 单路径规划

精确 query `帮我规划队伍/客户/产品达成路径` 时，直接进入 NBEV 目标追问，再打开对应单一路径。

### 5.4 达成路径工作台

工作台标题为 `深圳分公司{业务季}达成路径规划`。

工作台包含：

- NBEV 目标值汇总
- 产品规划值
- 客户规划值
- 队伍规划值
- 产品达成路径
- 客户达成路径
- 队伍达成路径

每个路径维度包含：

- 过往数据分析
- AI 测算方案
- 可调整分布卡
- 路径确认按钮

底部确认区根据当前路径状态变化：

- 未确认：展示 `确认{路径}规划`
- 单路径确认后：引导继续其他路径
- 三条路径均确认后：可最终确认达成路径规划

## 6. 目标拆解

### 6.1 触发方式

触发 query：

- `目标制定`
- `目标拆解`
- `拆解推动目标`

### 6.2 两步追问

目标拆解前需要确认：

1. 业务季
   - 司庆季
   - 6-8 月服务季

2. 推动目标
   - 总部下发推动目标
   - 自定义目标

### 6.3 AI 输出

AI 输出内容包括：

- 已读取 12 个网点综合数据。
- 结合历史表现与近期经营情况生成月度目标拆解。
- 说明拆解参考、合计校验、重点关注网点。
- 生成目标拆解工件卡。

### 6.4 目标拆解工作台

目标拆解工作台包含：

- 季度推动目标总览
- 月度目标表
- 月度目标确认
- 按口径拆解到 12 个网点
- 方案 A/B/C 选择
- 网点目标编辑
- 三维承接判断
- 版本历史
- 暂存版本管理
- 底部确认栏

月度目标表字段：

- 月份
- 当月推动目标
- 推动目标占比
- 同比提升
- 去年同期 NBEV 达成值
- 去年同期 NBEV 占比

网点拆解表支持编辑目标值，编辑后触发联动校验与版本状态更新。

### 6.5 版本能力

目标拆解支持版本历史：

- 当前版本
- 暂存版本
- 已确认版本
- 复制为新版本
- 编辑暂存版本
- 删除暂存版本

暂存版本最多保留 5 个，且仅保留 30 天。

## 13. 名单工作台通用能力

达钻潜力、钻石达成、承保代理人、面谈对象四类名单工作台共享一套基础能力。

### 13.1 营业单位筛选

筛选为五级组织结构：

1. 二级机构：广东
2. 三级机构：深圳市等广东省城市
3. 业务发展区：深圳各区
4. 网点
5. 营业部/组

筛选面板包含：

- 面包屑
- 当前层级列表
- 确定按钮
- 清除筛选
- 当前筛选 tag

### 13.2 搜索

名单工作台均提供代理人搜索框，按姓名过滤。

### 13.3 分页

名单工作台使用分页底栏，支持：

- 页码切换
- 每页条数切换
- 跳转页码
- 空态提示

### 13.4 导出

点击导出按钮后 Toast 提示：

`正在为您下载代理人名单并推送到邮箱，请稍后去邮箱查看`

## 14. 代理人详情页

代理人详情页由名单工作台中的 `查看明细` 打开。

### 14.1 页面结构

代理人详情页在右侧工作台内展示，包含：

- 顶部面包屑/标题
- 代理人摘要
- AI 洞察 · 面谈要点
- 面谈框架与话术指引
- 代理人档案指标
- 底部工具栏

### 14.2 代理人摘要

摘要卡展示：

- 代理人姓名
- 标签：高才、二次入司、双金钻、连钻 15 月
- 工号
- P/M 职级
- 所属营业部/组

点击摘要卡进入代理人基础信息详情。

### 14.3 AI 洞察 · 面谈要点

AI 洞察为双列结构，包含两条带标题文案：

- 基本法利益要点
- 目标客户要点

该模块用于在详情页首屏给出面谈准备重点。

### 14.4 面谈框架与话术指引

面谈框架分为：

- 谈目标
- 盘客户
- 定行动

话术指引支持展开、收起和换一换。

### 14.5 代理人档案指标

代理人详情页支持月份选择，默认 2026 年 5 月。

指标区包含：

#### 经营画像

- FYC 达成进展
- 业绩追踪
- 钻石达成

#### 客户经营

- 客经工作台
- 客户资源

#### 队伍发展

- 增员追踪
- 团队看板

#### 面谈历史

- 面谈档案

当前部分卡片点击后为 `功能开发中` Toast。

### 14.6 底部工具栏

代理人详情页底部工具栏包含：

- 面谈总结
- 架构图

其中：

- 面谈总结进入当前代理人的月度面谈总结列表。
- 架构图当前提示 `带参数,打开已有二级页面`。

## 15. 代理人基础信息页

基础信息页包含：

- 代理人姓名
- 工号
- P/M 职级
- 所属组织
- 推荐人
- 入司轨迹
- 标签与画像信息

- MBO 面谈

- 待面谈
