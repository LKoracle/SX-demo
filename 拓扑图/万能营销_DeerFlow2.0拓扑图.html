DeerFlow 闭环
DeerFlow 架构升级要点说明：
1. 面谈首要拦截（Primary Mechanism）：系统重构后，②号与③号"追踪管理智能体"作为核心流转关卡。无论是内勤督导高职级、还是外勤追踪基层，必须先通过"面谈辅助Skill"在沙箱中确立或更新代理人的 FYC 与件数目标，后续的客户经营、保障测算、以及问答陪练才允许读取上下文并开始流转。防止 AI 脱离业务目标盲目运行。
2. AIO Sandbox（隔离安全沙箱）：④号盘客和⑤号保障测算工具，全部由 DeerFlow 原生 Docker 沙箱托管。大模型在此阶段被赋予真实的 Python 执行能力，能够处理海量的平安客户标签筛选，并能运行复杂的金融险种精算公式，杜绝了大模型的数字幻觉。
3. 长期记忆与异步流回（Long-Term Memory Loop）：⑥号问答陪练产生的能力诊断数据，以及④号经营产生的业绩表现，通过 DeerFlow 的异步记忆机制，跨会话直接流回下一轮面谈名单中，从而动态调整下一次"面谈辅助"的沟通策略，构成完美业务闭环。
